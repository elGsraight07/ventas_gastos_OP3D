Configurar base de datos

Esta app usa Firebase de Google para guardar y sincronizar los datos en tiempo real entre todos tus dispositivos y usuarios. La configuración es gratuita.

1

Ve a console.firebase.google.com, crea un proyecto nuevo (gratis), activa Realtime Database en modo de prueba y copia la URL de tu base de datos.

2
Se ve así: https://nombre-proyecto-default-rtdb.firebaseio.com
3

En Configuración del proyecto → Tus apps → Agrega una app web. Copia el apiKey.

4
5

¿Solo quieres probar la app? Usar modo demo (datos locales, sin sincronización)
